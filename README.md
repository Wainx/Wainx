## 💭 做项目时，我会反复问自己

1. **场景是什么？** 谁在使用，卡在哪一步，怎样才算解决了问题？
2. **取舍是什么？** 实现成本、维护难度和不确定性，是否都考虑到了？
3. **怎样验证？** 不只让功能跑起来，也关注部署、反馈和下一次迭代。
