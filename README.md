### 关于我

我的项目涵盖 Java 后端、Web 页面与浏览器游戏。在这里记录业务系统的实现，也保留有趣的创意实验。

- ⚙️ **后端实践**：Spring Boot、Redis 并发控制与 WebSocket 实时通信。
- 🎮 **创意开发**：用 JavaScript / PixiJS 构建浏览器游戏。
