## 💭 关于 AI 提效，我会多问一步

1. **先看任务，再谈工具。** 工作卡在哪一步？哪些环节重复，哪些判断仍需要人来做？
2. **把检查与返工也算进去。** 省下的时间，是否超过检查和返工的成本？结果能否依据原始需求得到验证？
3. **让方法能够复用。** 有效尝试中的上下文、操作步骤和检查方式，能否让下一位使用者看懂并用起来？
4. **让实施足够简单。** 先跑通小范围流程；日常记录与正式变更分开，避免让自动化反而增加管理负担。

经验在积累，判断也在打磨。我希望自己既能讲清工具怎么用，也能解释：**为什么这一步值得用它。** 代码之外，我也用摄影记录光影与日常。
